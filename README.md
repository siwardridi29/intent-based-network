1_LANCEMENT DE MININET

Le lancement de la topologie mininet pour ce projet se fait à l'aide du fichier : Start-mininet.sh.

A exécuter : ./Start-mininet.sh dans le dossier racine du projet.




2_LANCEMENT DE RYU

Pour lancer ryu il faut se déplacer dans le dossier ryu et exécuter : ./Start-ryu.sh.

NOTE: Pensez à adapter le chemin de l'environnement dans le script de lancement de ryu. 



2_LANCEMENT DE l'API FLASK

Pour le lancement il faut se déplacer dans le dossier Api et exécuter : ./Start-api.sh. Pensez à adapter le nom de l'environnement.


4_ADRESSE DU DASHBOARD : http://localhost:5000/dashboard
